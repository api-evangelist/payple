# Payple

> Payple (페이플) is a South Korean payment gateway (PG) and fintech provider offering
> online payment acceptance for domestic and international cards, bank-account (real-time
> account) payments, recurring/billing-key payments, link payments, identity verification,
> and settlement/payout (Hub) services. Integration is via a hosted payment window plus a
> REST API (v2). This file is generated by the API Evangelist enrichment pipeline from the
> Payple developer center and the PAYPLECORP GitHub organization.

## Authentication

- Server-side partner auth: PCD_CST_ID + PCD_CUST_KEY -> auth key (PCD_AUTH_KEY).
- Client-side payment window: public clientKey (domain/Referer + HTTPS restricted).
- No OAuth2 / OAuth scopes.

## Notes for agents

- Errors are proprietary result codes (T/R/A/C/N/D prefixes + screen-specific families), paired with a Korean message; see errors/payple-response-codes.yml.
- Idempotency: duplicate payments are rejected by merchant order id (PCD_PAY_OID).
- Async result delivery is a merchant callback URL (PCD_RST_URL); re-confirm via the approval/confirm endpoint before fulfilling.
